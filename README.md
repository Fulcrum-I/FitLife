# FitLife

FitLife - приложение на Python, которое помогает людям следить за здоровьем, рассчитывает индекс массы тела
и рекомендуемую норму воды в день.

## Возможности

- знакомство с пользователем (ввод имени, возраста)
- ввод его параметров (вес, рост)
- расчёт индекса массы тела (ИМТ)
- выдача рекомендаций по потреблению воды

## Запуск проекта

Создайте и активируйте виртуальное окружение:

python -m venv venv
source venv/Scripts/activate

Установите зависимости:

pip install -r requirements.txt

Запустите программу:

python fit_life.py
